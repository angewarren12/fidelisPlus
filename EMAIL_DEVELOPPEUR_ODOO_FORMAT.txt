1️⃣  ARCHITECTURE

FidelisPlus → Odoo (PUSH)
├─ Trigger: Création prospect/client
├─ Mécanisme: Job Laravel asynchrone
├─ Endpoint: POST /api/sale_odoo/v1/partners
└─ Idempotence: external_ref = "fidelis-company-{id}"

Odoo → FidelisPlus (PULL)  
├─ Trigger: Cron (php artisan odoo:sync)
├─ Endpoints:
│  ├─ GET /api/sale_odoo/v1/partners
│  ├─ GET /api/sale_odoo/v1/vehicles
│  └─ GET /api/sale_odoo/v1/sale_orders
└─ Tracking: Curseur last_synced_at par resource

❌ PROBLÈMES DÉTECTÉS

PROBLÈME #1: HTTP 500 - modified_since
  Endpoint: GET /api/sale_odoo/v1/partners?modified_since=2026-08-13T15:36:12+00:00
  Code: 500 Internal Server Error
  Message: "An unexpected error occurred"
  Cause: Problème parsing timestamp ISO 8601 côté Odoo
  Impact: Impossible de faire du pull incrémental
  Workaround: Utiliser modified_since=null (pull complet)
  Action requise: Corriger le bug Odoo API
  
PROBLÈME #2: HTTP 403 - Accès Vehicles
  Endpoint: GET /api/sale_odoo/v1/vehicles
  Code: 403 Forbidden
  Cause: Utilisateur API sans groupe "Parc automobile / Administrateur"
  Impact: Impossible de synchroniser les flottes
  Groupes requis:
    - Parc automobile / Administrateur
    - Parc automobile / Gestionnaire : Gérer tous les véhicules
  Action requise: Ajouter permissions à l'utilisateur API
  
PROBLÈME #3: HTTP 403 - Accès Sale Orders
  Endpoint: GET /api/sale_odoo/v1/sale_orders
  Code: 403 Forbidden
  Cause: Utilisateur API sans permissions Ventes
  Impact: Impossible de synchroniser les devis
  Groupes requis:
    - Comptabilité / Facturation (optionnel)
    - Ventes / Administrateur
    - Ventes / Utilisateur : mes documents seulement
  Action requise: Ajouter permissions à l'utilisateur API
