## 1. ARCHITECTURE DE SYNCHRONISATION

### Direction 1: FidelisPlus → Odoo (Push)
- Trigger: Création d'un prospect ou d'un client dans FidelisPlus
- Mécanisme: Job Laravel asynchrone + Queue
- Endpoint: POST /api/sale_odoo/v1/partners
- Idempotence: Chaque ressource porte un external_ref stable
- Format: { "external_ref": "fidelis-company-{id}", "name": ..., "email": ..., ... }

### Direction 2: Odoo → FidelisPlus (Pull)
- Trigger: Cron planifié (à configurer)
- Commande: php artisan odoo:sync
- Endpoints: 
  - GET /api/sale_odoo/v1/partners (prospects/clients)
  - GET /api/sale_odoo/v1/vehicles (flottes)
  - GET /api/sale_odoo/v1/sale_orders (devis)
- Tracking: Curseur de dernière synchro par resource (table odoo_sync_cursors)

### ❌ BLOCAGES IDENTIFIÉS

#### 2.4 Erreur HTTP 500 sur paramètre modified_since
- Issue: GET /api/sale_odoo/v1/partners?modified_since=2026-08-13T15:36:12+00:00
- Statut: HTTP 500 Internal Server Error
- Message: "An unexpected error occurred"
- Cause: Problème côté Odoo lors du parsing du timestamp ISO 8601
- Impact: Impossible de faire un pull incrémental (modified_since)
- Workaround: Utiliser modified_since=null → pull complet
- Status: À CORRIGER (Côté Odoo)

#### 2.5 Erreur HTTP 403 - Permissions insuffisantes (Vehicles)
- Issue: GET /api/sale_odoo/v1/vehicles
- Statut: HTTP 403 Access Denied
- Message: "Vous n'êtes pas autorisé à accéder aux enregistrements 'Véhicule' (fleet.vehicle)"
- Cause: L'utilisateur API n'a pas le groupe "Parc automobile / Administrateur"
- Impact: Impossible de synchroniser les flottes depuis Odoo
- Required groups: 
  - "Parc automobile / Administrateur"
  - "Parc automobile / Gestionnaire : Gérer tous les véhicules"
- Status: À CORRIGER (Configuration Odoo)

#### 2.6 Erreur HTTP 403 - Permissions insuffisantes (Sale Orders)
- Issue: GET /api/sale_odoo/v1/sale_orders
- Statut: HTTP 403 Access Denied
- Message: "Vous n'êtes pas autorisé à accéder aux enregistrements 'Commande client' (sale.order)"
- Cause: L'utilisateur API n'a pas les permissions Ventes
- Impact: Impossible de synchroniser les devis depuis Odoo
- Required groups:
  - "Comptabilité / Facturation" (optionnel)
  - "Ventes / Administrateur"
  - "Ventes / Utilisateur : mes documents seulement"
- Status: À CORRIGER (Configuration Odoo)

#### 2.7 Pas de partners FidelisPlus dans Odoo
- Observation: Aucun partner avec external_ref commençant par "fidelis-"
- Cause probable: 
  - Aucun prospect créé en FidelisPlus, OU
  - Queue worker n'a pas exécuté les jobs de sync, OU
  - Créations de prospects avant la validation email obligatoire
- Impact: Synchronisation FidelisPlus → Odoo non testée
- Next step: Créer un prospect via interface et observer les logs
- Status: À TESTER
