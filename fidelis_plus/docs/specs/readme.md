# Spécifications Fidélité (PPTX)

Les cahiers des charges originaux (format PPTX) détaillant les règles de fidélité, les paliers de points (flotte, parrainage, bonus) et les interfaces souhaitées sont stockés dans le dossier `storage/` pour ne pas alourdir le dépôt Git tout en restant accessibles.

- [CARTE DE FIDELITE -2025 (1).pptx](../../storage/CARTE%20DE%20FIDELITE%20-2025%20(1).pptx)
- [Carte de Fidelité Mayelia -Version Simplifié 2026 (1).pptx](../../storage/Carte%20de%20Fidelit%C3%A9%20Mayelia%20-Version%20Simplifi%C3%A9%202026%20(1).pptx)

## Contexte
Ces documents décrivent :
- Les segments métier : apporteur d'affaires, garage, gestionnaire de parc.
- Les paliers liés à la taille de la flotte.
- Les bonus exceptionnels (100% de la flotte enregistrée, parrainage, alertes SMS).
- La vision cible des rapports et exports pour les commerciaux.

> **Note** : Une analyse d'écart (Gap Analysis) entre ces spécifications et l'implémentation V1 est documentée dans les tickets/backlog du projet.
